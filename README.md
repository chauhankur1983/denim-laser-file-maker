# Denim Laser File Maker

Turns a photo of a washed jean into a grayscale laser file (darker means more laser power), with a preview of the result.

- Use lasso or brush selection so that only the areas you choose get lasered.
- Runs entirely in the browser. Photos are never uploaded anywhere.

**Live tool:** https://chauhankur1983.github.io/denim-laser-file-maker/

Prototype by Ankur Chauhan.
